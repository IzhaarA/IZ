# Makkie Wholesalers: logo and brand guide

## Which logo goes where
| Use | File |
|---|---|
| **Ads (TikTok, Instagram, Facebook, posters, reels, carousels): use only the new MW oval** | `makkies-mw-oval-hires.png` (or the `-1200`, `-600`, `-300` sizes) |
| Website header, footer and anything on a dark background | `makkies-logo-for-dark-backgrounds.png` |
| Invoices, letterheads, email and anything on white | `makkies-logo.png` |
| Social media profile picture (every platform) | `../profile-picture/makkies-profile-picture.png` |
| Website icons and share image | `web/` |

## Rules
- **Future ads use just the new MW oval**, not the full "Makkie Wholesalers" logo and not the old plain MW letters.
- Tagline: **Blankets • Beads • Traditional Goods**.
- MW colours:
  - M stripes: plum #45203F, yellow #FFE14F, blue #0350EA, red #FF0141, green #05B56D.
  - W red: #ED191D with black #1A1210.
  - Oval: #1B181D.
- Contact details:
  - makkies.co.za
  - WhatsApp 072 323 5469
  - orders@makkies.co.za
  - @makkiewholesalers on TikTok, Instagram and Facebook

## Rebuilding
- `build-mw-oval.py` redraws the MW oval at 8× from the original artwork, so it stays sharp at any size.
- `compose-logo.py` puts the full logo together.
